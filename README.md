# GOO DAARI V3

Local discovery website for GOO DAARI.

## V3 changes
- Telugu brand tagline: **GOO DAARI — అన్నిటికీ ఒకటే దారి.**
- Added About Us page.
- Added variable location selector.
- Live directory locations: Peddapuram and Samalkota.
- Expansion locations: Pithapuram, Kakinada and Rajamahendravaram.
- Location selection is remembered in the browser and filters search/listings.
- Locations can be added later by editing `location.js` and adding listings to `data.js`.
- No rides section included in this launch.
